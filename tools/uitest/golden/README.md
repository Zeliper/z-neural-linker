# 골든 이미지

`expect-shot <이름>` 이 견주는 기준 화면을 `<이름>.ppm`(P6) 으로 둔다. 지금은 비어 있다 —
화면이 아직 바뀌는 중이라 기준을 굳히지 않았다. 만드는 절차는 `../README.md` "골든 이미지" 절 참고.

PPM 인 이유: 헤더 뒤가 그대로 RGB 바이트라 비교 도구(`../ppmdiff.py`)가 표준 라이브러리만으로 끝난다.
1600×1000 한 장이 4.6 MB 라 저장소가 커진다 — 전체 화면보다 바뀌는 영역만 잘라 두는 편이 낫다:

```
expect-shot 모델-캔버스 "200,60 800x600"
```
